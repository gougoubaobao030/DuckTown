### 把对象池拆成几个部分——以蘑菇炮弹为例子

- 可以来个基础的ObjectPool<T>
- 再通过
- ```Mushroom: objectPool<Mushroom>```
- 来实现具体类

#### 但现在我们单独写一个作为练习
- 分成大概...5个部分
- C#中使用Queue，因为是典型的回收再利用，先进先出效率高
- 初始化的时候先初始化几个
- 不够要再动态扩容
- 有一个return函数，外部调用
- 函数接口
- create
- get
- return

#### ⑥大要素
1. 缓存池
2. Get可取出
3. return要回收
4. 预制体
5. 初始化逻辑，先生成几个
6. 个人补充：内部生成函数
